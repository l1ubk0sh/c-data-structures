# C Data Structures

Singly linked list in C with manual memory management and unit tests.

## Features
- push_front / push_back / pop_front
- find, reverse
- Memory released with list_free

## Build and test
Open `c-data-structures.slnx` in Visual Studio 2022 and run with Ctrl+F5.

## What I learned
Pointer manipulation, heap allocation and ownership, writing tests with assert.
